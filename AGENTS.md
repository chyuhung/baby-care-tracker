## Architecture
- **Backend**: Go + gin on `:8080`, modernc.org/sqlite, WebSocket broadcast via Hub pattern
- **Frontend**: Vue 3 + Pinia + Vue Router, Vite dev server on `:5173`
- **DB**: `C:\app\data\app.db`; DATETIME columns always return UTC with `Z` suffix

## Key Decisions
- Timezone: client offset header, not server TZ; stored times are UTC
- Calendar dates (birth date, growth measured date) are pure local `YYYY-MM-DD`, never instants — no timezone conversion on store/read
- Record events: `record-created` and `record-deleted` CustomEvents on `window` — WebSocket broadcasts trigger these; delete handlers dispatch directly for instant UI
- Top chrome: opaque, not edge-to-edge. `default` status bar (iOS paints it, takes `theme-color`) + `.nav-surface` top bars in the same `--surface` ⇒ the status bar and the title bar read as one block. Do **not** switch to `black-translucent` unless the top bar also goes dark — it forces white status-bar text, which is invisible on a light bar
- Nav title: fixed 17px semibold, centered, no large-title morph. WeChat convention, chosen over the iOS Large Title HIG pattern; a centered 34px title is not a real iOS or Chinese-app pattern
- CSS custom properties are resolved **where declared, then inherited** — `data-theme` is set on a div inside `#app` (`App.vue:2`), not on `<html>`, so a token declared in the `:root` block using `var(--some-theme-token)` will **not** re-resolve for male/dark. Declare per theme block.
